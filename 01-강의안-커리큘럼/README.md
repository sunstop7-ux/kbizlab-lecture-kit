# 01 · 강의안 · 커리큘럼

법인컨설팅 강의의 모듈별 강의안입니다. 모듈은 독립적으로 들을 수 있고, 4개를 이어 들으면 **"설립 → 자본 → 승계 → 지원제도·노무"** 로 이어지는 한 사이클이 완성됩니다.

## 공통 진행 방식

1. **개념 정리 (20%)** — 제도가 존재하는 이유와 전체 구조를 먼저 잡습니다.
2. **사례·판례 (40%)** — 실제 회사에서 무엇이 문제가 되었는지 확인합니다.
3. **워크시트 (40%)** — 우리 회사 숫자를 넣어 직접 계산하고, 다음 할 일을 정합니다.

## 수강생 준비물

- 최근 3개년 재무제표(또는 표준재무제표증명)
- 법인등기사항전부증명서, 정관 사본
- 주주명부(지분율), 임원 현황
- 궁금한 점 3가지 — 강의 중 워크시트에 반영합니다.

> 세법·지원제도 요건은 개정이 잦습니다. 강의안의 기준일과 실제 신청 시점의 기준이 다를 수 있으므로, 신청 전 관할 기관과 전문가 확인을 권합니다.
