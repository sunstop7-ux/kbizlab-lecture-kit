# 법인컨설팅 용어 정리

강의에 자주 나오는 용어를 한 줄로 정리했습니다. 괄호 안은 실무에서 함께 쓰는 표현입니다.

## 지배구조

| 용어 | 뜻 |
| --- | --- |
| 보통결의 | 주주총회 출석 주주의 과반수 찬성이 필요한 일반 안건 결의 |
| 특별결의 | 정관 변경·합병·해산 등 중대 안건. 보통 발행주식 총수의 3분의 1 이상 출석과 출석 3분의 2 이상 찬성이 필요 |
| 종류주식 | 의결권 배제·제한, 우선배당 등 특약이 붙은 주식 |
| 주주간계약 | 주주 사이의 권리·의무를 정한 계약(우선매수권, 동반매도권 등) |
| 우선매수권 | 다른 주주가 주식을 팔 때 먼저 살 수 있는 권리 |
| 동반매도권(태그얼롱) | 대주주가 지분을 팔 때 소수주주도 같은 조건으로 팔 수 있는 권리 |
| 전자투표·서면투표 | 주주총회에 직접 가지 않고 의결권을 행사하는 방법 |

## 자본·재무

| 용어 | 뜻 |
| --- | --- |
| 자기자본 | 자본금 + 이익잉여금 등, 갚을 의무가 없는 돈 |
| 자본잠식 | 누적 결손으로 자본총계가 자본금보다 작아진 상태 |
| 감자 | 자본금을 줄이는 절차. 채권자 보호 절차가 필요 |
| 무상증자(자본전입) | 이익잉여금이나 자본준비금을 자본금으로 옮겨 주식을 나눠주는 것 |
| 가지급금 | 회사가 주주·임원에게 업무와 무관하게 지급해 회수되지 않은 금액 |
| 가수금 | 주주·임원이 회사에 일시적으로 넣어둔 돈(가지급금의 반대 개념) |
| 인정이자 | 가지급금 등에 대해 세법상 이자를 인정해 소득으로 보는 것 |
| 전환사채(CB) | 일정 조건에 따라 주식으로 바뀔 수 있는 사채 |
| 신주인수권부사채(BW) | 주식을 살 수 있는 권리가 붙은 사채 |
| 리픽싱 | 주가 하락 시 전환가액을 조정하는 조항 |
| 개인투자조합 | 개인 투자자 자금을 모아 기업에 투자하는 조합 |

## 승계·세무

| 용어 | 뜻 |
| --- | --- |
| 가업상속공제 | 가업을 상속받을 때 일정 요건 아래 상속세에서 공제하는 제도 |
| 가업승계 증여특례 | 생전 증여 시 증여세를 납부유예·감면하는 제도 |
| 사후관리 | 공제·특례를 받은 뒤 일정 기간 요건을 유지해야 하는 의무 |
| 증여재원 | 증여세를 낼 돈. 출처를 증빙해야 함 |
| 기업가치 평가 | 주식 가치를 산정하는 절차(순자산·수익·시장 접근법) |
| 부당행위계산부인 | 특수관계자와의 거래로 세부담을 줄이면 세법이 이를 부인하는 제도 |
| 소득처분 | 법인 장부상 인출을 상여·배당 등으로 처분해 개인에게 과세하는 절차 |

## 지원제도·노무

| 용어 | 뜻 |
| --- | --- |
| 기업부설연구소 | 기업이 자체 연구개발을 위해 설치·신고한 연구 조직 |
| 전담부서 | 연구소 규모 요건을 못 갖춘 기업이 두는 연구 전담 조직 |
| 연구노트 | 연구 과정과 결과를 기록한 공식 문서. R&D 증빙의 기본 |
| 벤처기업확인 | 기술성·혁신성 등을 심사해 벤처기업임을 확인하는 제도 |
| 고용증대 세액공제 | 상시근로자 수가 늘어난 중소·중견기업에 주는 세액공제 |
| 고용장려금 | 청년·고령자·장애인 등 취업 취약계층 채용 시 지급되는 지원금 |
| 포괄임금제 | 수당을 미리 포함해 임금을 정하는 방식. 적법 요건이 엄격함 |
| 통상임금 | 수당·퇴직금 계산의 기준이 되는 임금 |
| 취업규칙 | 근로조건과 복무 규율을 정한 규칙. 일정 규모 이상은 신고 의무 |
