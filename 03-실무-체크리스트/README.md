# 03 · 실무 체크리스트

강의 현장에서 그대로 인쇄해 쓰는 점검표입니다. 항목을 체크하면서 **"우리 회사에 없는 것"** 을 찾는 것이 목적입니다.

- [체크리스트 모음 바로 가기](체크리스트-모음.md)

## 목록

| 체크리스트 | 사용 시점 |
| --- | --- |
| 법인 설립 체크리스트 | 설립 전 ~ 등기 후 1개월 |
| 자본·가지급금 점검표 | 결산 전, 투자 유치 전 |
| 가업승계 준비 점검표 | 승계 3~10년 전 |
| 연구소·벤처·고용지원금 점검표 | 매년 1월, 채용 전 |
| 노무 리스크 점검표 | 분기 1회 |
