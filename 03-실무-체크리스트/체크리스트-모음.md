# 실무 체크리스트 모음

> 인쇄해서 회의에 가져가세요. 체크되지 않은 항목이 이번 분기의 과제입니다.
> 세법·제도 요건은 개정이 잦으므로, 신청 전 최신 기준을 확인하세요.

---

## 1. 법인 설립 체크리스트

### 설립 전
- [ ] 사업 목적과 업종 코드(한국표준산업분류) 확정
- [ ] 법인 형태 결정(주식회사 / 유한회사)
- [ ] 사업장 주소 확보(임대차계약 또는 본점 사용 승낙)
- [ ] 인허가 필요 업종 확인
- [ ] 상호 검색(동일 상호·상표 충돌)
- [ ] 자본금 규모와 납입 계획 수립
- [ ] 주주·지분율·의결권 구조 합의(문서화)

### 설립 절차
- [ ] 정관 작성(사업 목적, 주식, 양도 제한, 기관 구성)
- [ ] 발기인 총회 의사록 작성
- [ ] 자본금 납입(잔고증명)
- [ ] 설립 등기 신청(법무사·등기소)
- [ ] 사업자등록(홈택스 또는 세무서)
- [ ] 법인 인감·사용인감 신고
- [ ] 4대보험 사업장 성립 신고

### 설립 후 1개월
- [ ] 주주명부·주권(또는 전자등록) 정리
- [ ] 이사회·주주총회 의사록 보관 체계 마련
- [ ] 법인 계좌 개설, 카드·자금 집행 규정 수립
- [ ] 회계 처리 기준(결산기, 감가상각, 비용 인정 항목) 정리
- [ ] 급여·원천세 신고 일정 캘린더 등록

---

## 2. 자본·가지급금 점검표

- [ ] 가지급금 잔액과 발생 연도 파악
- [ ] 가지급금 성격 분류(업무 무관 / 일시 대여 / 비용 미처리)
- [ ] 인정이자 규모와 세무 영향 추정
- [ ] 정리 방법별 필요 자금·세부담 비교
- [ ] 정리 실행 일정(월별) 합의
- [ ] 이익잉여금 잔액과 배당 여력 확인
- [ ] 무상증자(자본전입) 가능 여부 검토
- [ ] 자본잠식 여부 확인(결손금·자본금 비교)
- [ ] 투자 유치 시 희석률 시뮬레이션
- [ ] CB·BW 계약서의 전환가액·리픽싱 조항 검토

---

## 3. 가업승계 준비 점검표

### 기본 요건
- [ ] 가업 영위 기간 확인(10년 이상 여부)
- [ ] 승계 대상 지분율과 보유 형태 정리
- [ ] 회사 규모(중소·중견) 확인
- [ ] 업종 요건 충족 여부 확인

### 승계자
- [ ] 승계자 선정 및 가족 합의
- [ ] 승계자 재직 기간·직위 확보
- [ ] 대표이사 취임 계획(시점·절차)
- [ ] 승계자 자금 마련 계획(증여재원)

### 실행
- [ ] 기업가치 평가 방식·시점 결정
- [ ] 증여 시점과 분산 증여 계획
- [ ] 증여세 납부 재원 확보
- [ ] 주주간계약·정관 갱신(승계 반영)
- [ ] 사후관리 요건(업종·자산·근로자 유지) 점검표 작성

---

## 4. 연구소·벤처·고용지원금 점검표

- [ ] 기업부설연구소/전담부서 신고 요건 충족 여부
- [ ] 연구 인력 자격·전담 여부 확인
- [ ] 연구 공간(전용 면적·시설) 확보
- [ ] 연구개발비 집행·연구노트 관리 체계
- [ ] R&D 세액공제 대상 비용 분류
- [ ] 벤처기업확인 유형 선택 및 신청 시기
- [ ] 채용 계획 대비 고용장려금 요건 확인
- [ ] 고용증대 세액공제 요건(상시근로자 수) 확인
- [ ] 사회보험료 지원 대상 여부
- [ ] 지원제도 중복 수혜 제한 확인
- [ ] 신청 기한 캘린더 등록

## 5. 노무 리스크 점검표

- [ ] 근로계약서 필수 기재 사항 및 교부
- [ ] 임금 구조(기본급·수당·성과급) 명확화
- [ ] 포괄임금제 적법 요건 충족
- [ ] 연장·야간·휴일근로 수당 산정 방식
- [ ] 연차 발생·사용·미사용 수당 정산
- [ ] 퇴직금 적립(퇴직연금 포함)
- [ ] 취업규칙 작성·신고(10인 이상)
- [ ] 4대보험 취득·상실 신고
- [ ] 근무기록(출퇴근) 보관
- [ ] 징계·해고 절차 문서화
- [ ] 퇴사 정산 기준과 지급 시점 규정
