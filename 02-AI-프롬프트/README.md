# 02 · AI 프롬프트

법인컨설팅 실무에서 **ChatGPT·Claude 등 AI 도구**에 그대로 붙여 넣어 쓰는 프롬프트 모음입니다.
AI는 초안을 만드는 도구입니다. 숫자와 법령은 반드시 원문과 대조하세요.

- [프롬프트 모음 바로 가기](법인컨설팅-AI-프롬프트-모음.md)

## 사용 원칙

1. **우리 회사 정보를 먼저 넣습니다.** AI는 맥락이 없으면 일반론만 돌려줍니다.
2. **숫자는 출처와 함께** 요구합니다. "추정"과 "확정"을 구분하게 시킵니다.
3. **법령·요건은 기준일을 명시**합니다. "2026년 기준"처럼 시점을 못 박습니다.
4. 결과는 **전문가 검토용 초안**으로만 사용합니다.

> 개인정보·회사 기밀(주민번호, 계좌번호, 미공개 재무자료)은 입력하지 마세요.
