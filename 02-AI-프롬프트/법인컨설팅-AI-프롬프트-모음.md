# 법인컨설팅 AI 프롬프트 모음

각 프롬프트의 `[ ]` 부분을 우리 회사 정보로 바꿔 붙여 넣으세요.
AI 답변은 **초안**입니다. 세법·법령 조항은 홈택스·국가법령정보센터 원문과 대조하세요.

---

## 1. 법인 설립 구조 진단

```
너는 20년 경력의 법인 설립·지배구조 컨설턴트다.
아래 조건으로 설립 구조 3안을 비교해 표로 정리해줘.

- 사업: [업종, 주요 제품·서비스]
- 예상 연매출: [금액], 초기 투자금: [금액]
- 공동창업자: [인원], 각자 역할: [역할], 희망 지분: [비율]
- 외부 투자 계획: [있음/없음, 시기]
- 향후 승계 계획: [있음/없음]

각 안에 대해 ①법인 형태 ②자본금·주식 구조 ③의결권 배분 ④정관에 넣을 조항
⑤예상되는 분쟁 지점을 적고, 마지막에 추천안과 그 이유를 3줄로 요약해줘.
숫자는 가정임을 명시하고, 확정 사실과 추정을 구분해줘.
```

## 2. 지분 희석 시뮬레이션

```
현재 지분 구조는 다음과 같다.
- 발행주식수: [주], 대표 지분: [%], 기타 주주: [%]

아래 자금 조달을 순서대로 실행할 때 지분율 변화를 단계별 표로 계산해줘.
1) 전환사채 [금액] 발행(전환가액 [원], 리픽싱 조항 [있음/없음])
2) 신주 투자 유치 [금액](투자 전 기업가치 [금액])
3) 스톡옵션 [수량] 행사

각 단계 후 대표 지분율과 3분의 1 미만으로 떨어지는지 여부를 표시하고,
지배력 방어를 위해 미리 정해야 할 계약 조항을 5개 제안해줘.
```

## 3. 가지급금 정리 시나리오

```
우리 회사 가지급금 현황이다.
- 잔액: [금액], 발생 연도: [연도], 주요 사유: [대표 가수금·차입·개인 용도 등]
- 회사 이익잉여금: [금액], 대표 개인 자금 사정: [설명]

가지급금을 정리하는 방법(현금 상환, 급여·상여 전환, 배당, 손익거래 전환)을
①필요 자금 ②세부담 발생 지점 ③실행 난이도 ④리스크 순으로 비교표로 정리하고,
3년에 걸친 정리 순서안을 월 단위 과제로 만들어줘.
세율과 한도는 기준일을 명시하고 '확인 필요'로 표시해줘.
```

## 4. 가업승계 시나리오

```
가업승계를 준비하는 회사다.
- 업종: [업종], 설립: [연도], 가업 영위 기간: [연수]
- 대표(현 승계자) 나이: [나이], 승계자: [관계·나이·현 직위·재직 기간]
- 지분: 대표 [%], 배우자 [%], 승계자 [%], 기타 [%]
- 회사 순자산: [금액], 연 매출: [금액], 임직원: [명]
- 승계자 자금 여력: [금액]

①상속 ②증여 ③매매 3가지 경로의 장단점과 예상 쟁점을 비교하고,
5년 로드맵(연도별 과제)과 사후관리 체크포인트를 작성해줘.
가업상속공제·가업승계 증여특례는 '요건 충족 여부를 확인해야 하는 항목'으로
목록화하고, 최신 기준 확인이 필요하다는 점을 명시해줘.
```

## 5. 기업부설연구소 설립 검토

```
기업부설연구소 설립을 검토 중이다.
- 업종: [업종], 매출: [금액], 연구 인력: [명·전공·경력]
- 연구 공간: [면적·소유/임대], 예상 연 연구개발비: [금액]
- 개발 과제: [과제 1~3]

①신고 요건 충족 여부를 항목별 체크표로 ②부족한 부분과 보완 방법
③인정 후 받을 수 있는 세제·과제 혜택 ④사후관리에서 흔히 놓치는 점
을 정리해줘. 요건은 'KOITA 신고 기준 확인 필요'로 표시해줘.
```

## 6. 벤처기업확인 유형 매칭

```
우리 회사 정보로 벤처기업확인 유형을 매칭해줘.
- 업종: [업종], 업력: [연수], 매출: [금액], 연구개발비 비중: [%]
- 특허: [건수·내용], 투자 유치: [금액·시기], 고용: [명]
- 목적: [세제 혜택 / 정책자금 / 입찰 가점]

유형별 요건 대비 우리 회사의 충족/미충족을 표로 정리하고,
가장 승산 높은 유형 2개와 준비 서류 목록을 제안해줘.
```

## 7. 고용지원금 매칭 캘린더

```
아래 채용 계획에 맞춰 신청 가능한 고용 관련 지원제도와 세액공제를 정리해줘.
- 채용 예정: [인원·연령·경력·고용형태·시기]
- 현재 인원: [명], 3년 전 인원: [명]
- 회사 규모: [중소/중견], 지역: [지역]

제도명·지원 내용·신청 시점·필요 서류·중복 제한을 표로 만들고,
연간 신청 캘린더(월별)로 재배열해줘. 한도와 요건은 연도별 변동을 명시해줘.
```

## 8. 노무 리스크 감사

```
아래 인사 제도를 노무사 관점에서 점검해줘.
- 근로계약 형태: [정규/계약/파견], 임금 구조: [기본급·수당·성과급]
- 근무 형태: [주 5일, 연장·야간·휴일 근로 여부]
- 포괄임금제: [적용 여부·대상]
- 취업규칙: [있음/없음·신고 여부], 퇴직금: [제도]

①법적 리스크가 큰 항목 순으로 5개 ②각 항목의 개선안
③퇴사 정산에서 분쟁이 생길 지점 ④필요한 문서·기록을 정리해줘.
```

## 활용 팁

- 한 번에 하나의 질문만 던지면 답이 정확해집니다.
- "표로 정리해줘", "확정/추정을 구분해줘", "확인 필요 항목을 표시해줘"를 항상 붙이세요.
- 같은 프롬프트를 회사 3곳에 적용해 비교하면 컨설팅 보고서의 뼈대가 됩니다.
